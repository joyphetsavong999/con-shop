# ขายเฉพาะจำนวนเต็มของหน่วยขาย ห้ามขายเป็นเศษ

ร้านวัสดุก่อสร้างมีสินค้าที่ผู้คนคิดปริมาณเป็นหน่วยวัด (กระเบื้องเป็น ตร.ม. เหล็กเป็น กก.)
ซึ่งแปลงเป็นหน่วยขายแล้วไม่ลงตัว (20 ตร.ม. = 13.89 กล่อง)
เราตัดสินใจว่าระบบจะ **ไม่รับการสั่งเป็นเศษทุกกรณี** ลูกค้าต้องสั่งจำนวนเต็มของหน่วยขายเสมอ และหน่วยวัดใช้เป็นข้อมูลช่วยคินแสดงผลเท่านั้น

ผลที่ตามมาคือระบบไม่มีกฎปัดเศษที่ไหนเลย ไม่ต้องมีการตัดสินใจว่าปัดขึ้นหรือลง
และสต็อกนับได้ตรงกับจำนวนที่ขายจริงเสมอ

## Considered Options

- **เปิด flag รายสินค้า** ให้บางสินค้าขายเป็นเศษได้ (เช่น กระเบื้องขายแยกแผ่น เหล็กตัดยาว)
  ยืดหยุ่นกว่า แต่ทุกจุดที่รับปริมาณต้องรองรับการปัดเศษ และต้องตัดสินใจเรื่องปัดขึ้นหรือลง ซึ่งเป็นค่าเริ่มต้นของความไม่พอใจลูกค้า
- **ให้ลูกค้าสั่งเป็นหน่วยวัดได้** แล้วระบบแปลงเป็นหน่วยขายให้
  ตรงกับสิ่งที่ลูกค้าคิดมากที่สุด แต่ต้องมีอัตราแปลงที่ชัดเจนสำหรับทุกสินค้า ซึ่งหลายสินค้าไม่ซ้อนกันจริง

## Consequences

- ตัดความสามารถขายกระเบื้องแยกแผ่น และการตัดเหล็กตามความยาวที่ลูกค้ากำหนด
- ถ้าภายหลังต้องการความสามารถนี้ ต้องเพิ่มเป็น ADR ฉบับใหม่ และค่อยดูว่าจะทำแบบ flag รายสินค้าหรือทั้งระบบ
