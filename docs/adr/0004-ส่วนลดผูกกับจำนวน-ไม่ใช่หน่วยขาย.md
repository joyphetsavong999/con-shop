# ส่วนลดปริมาณผูกกับจำนวนที่ซื้อจริง ไม่ผูกกับหน่วยขายที่เลือก

ระบบแปลงทุกรายการเป็นหน่วยพื้นฐานก่อนคิดส่วนลด ดังนั้นลูกค้าที่สั่ง 80 ถุง
จะได้ส่วนลดเดียวกับลูกค้าที่สั่ง 2 พาเลต (ซึ่งเท่ากับ 80 ถุง) เพราะได้จำนวนหน่วยพื้นฐานเท่ากัน

หน่วยขายเป็นแค่หน่วยสะดวกในการกรอกจำนวน ไม่ใช่ช่องทางที่ทำให้ได้ราคาถูกกว่า

## Considered Options

- **ผูกกับหน่วยที่ลูกค้าเลือกซื้อ** ร้านคุมต้นทุนได้ เพราะการขนเป็นพาเลตถูกกว่า
  และส่วนลดจึงแทนค่าขนส่งจริง แต่ลูกค้าที่สั่งของเท่ากันจะได้ราคาต่างกัน
  ต้องอธิบายให้เข้าใจและต้องกันไม่ให้เลือกผิดหน่วยจนเสียเงิน
- **ไม่มีส่วนลดพาเลตเลย ใช้ราคาส่งเป็นตัวแทน** โมเดลราคาง่ายที่สุด
  แต่ลูกค้าที่ซื้อเกินขั้นต่นเพียงถุงเดียวจะเสียเปรียบเทียบกับคนที่ซื้อมากโดยไม่มีเหตุผล

## Consequences

- **ไม่มี "ราคาพาเลต" ในระบบ** ผู้ที่อ่านโค้ดโดยไม่รู้บริบทจะไปสร้างตารางราคาต่อหน่วยขายขึ้นมาเอง เพราะเป็นสิ่งที่ทุกเว็บขายวัสดุใช้
- ร้านต้องรับภาระการขนแยกเป็นถุงที่ได้ราคาตามปริมาณ ต้องชดเชยด้วยค่าขนส่งหรือเงื่อนไขขั้นต่ำที่แยกต่างหาก
- ข้อนี้แยกจาก "เกณฑ์ปริมาณ" ซึ่งเป็นคนละกลไก — เกณฑ์ปริมาณคุมการได้รับราคาส่ง ส่วนนี้คิดเพิ่มจากจำนวน
