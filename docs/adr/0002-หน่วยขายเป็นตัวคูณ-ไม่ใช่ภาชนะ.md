# หน่วยขายเป็นตัวคูณของหน่วยพื้นฐาน ไม่ใช่ภาชนะจัดเก็บ

ปูนซีเมนต์ที่ขายเป็นถุง (หน่วยพื้นฐาน) และที่ขายเป็นพาเลต (หน่วยขาย) เป็น **สินค้าเดียวกัน**
และพาเลตเป็นตัวคูณจำนวนเต็มของหน่วยพื้นฐาน ไม่ใช่ภาชนะที่ต้องขายครบก้อน

ถ้ามีปูนเหลือ 35 ถุง ก็ยังขาย "1 พาเลต" ได้ เพราะ 1 พาเลต = 40 ถุง เสมอ
ไม่ว่าของจะครบก้อนหรือไม่ก็ตาม

## Considered Options

- **พาเลตเป็นภาชนะ ต้องขายครบเท่านั้น** โมเดลตรงกับความจริงเชิงกายภาพและนับสต็อกง่ายที่สุด
  แต่ของที่เหลือ 35 ถุงจะขายไม่ได้เลยจนกว่าจะมีลูกค้ามาซื้อถุง และผู้รับเหมามักยกเลิกออเดอร์เพราะรอพาเลตใหม่
  ซึ่งเป็นพฤติกรรมที่แทบไม่เกิดขึ้นกับร้านจริง
- **ตั้งหน่วยขายได้รายสินค้า** ยืดหยุ่นที่สุด แต่ผู้ดูแลต้องตั้งค่าทีละสินค้า
  และเสี่ยงตั้งผิด (ใส่ 50 ถุงต่อพาเลตทั้งที่จริง 40) ลูกค้าก็เห็นหน่วยแปลกๆ ที่ตั้งไว้

## Consequences

- ต้องแยก "หน่วยขาย" ออกจาก "ภาชนะจัดเก็บ" ในโมเดลข้อมูล เพราะสองอย่างนี้ไม่ได้แปลนกัน
- ต้องระวังผู้ที่อ่านโค้ดจะเข้าใจผิดว่าพาเลตคือสินค้าที่ต้องขายครบก้อน ตรงกับธรรมชาติของของจริงมากกว่า
